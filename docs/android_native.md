# Умный Календарь для Android

Проект Android Studio на этом компьютере расположен в `C:\Users\shibi\AndroidStudioProjects\Kursovoi_project`. Откройте эту папку через **File → Open**, дождитесь Gradle Sync, выберите модуль **app**, вариант **debug** и устройство, затем нажмите **Run**. Нужен Android 7.0 (API 24) или новее. Версии Gradle и Android Gradle Plugin заданы проектом, compileSdk и targetSdk — 37.

## Первый запуск на телефоне по Wi-Fi

1. Подключите телефон и компьютер к одной домашней или учебной сети. Выполните `ipconfig` на компьютере и найдите IPv4 активного Wi-Fi или Ethernet-адаптера. Далее подставьте его вместо `<LAN-IP>`.
2. В репозитории календаря подготовьте `backend/.env` и БД по основной [инструкции](../README.md). Для Docker из корня репозитория выполните `docker compose up -d backend`. Сервис публикует порт 8000 и запускает Uvicorn на `0.0.0.0`. При ручном запуске из каталога `backend` с подготовленной БД выполните `.\venv\Scripts\python -m uvicorn main:app --env-file .env --host 0.0.0.0 --port 8000`.
3. На телефоне откройте в браузере `http://<LAN-IP>:8000/health`. Ожидаемый ответ — `{"status":"ok"}`. При тайм-ауте проверьте IP, порт, изоляцию клиентов на роутере и правила брандмауэра. При необходимости разрешите входящий TCP 8000 **вручную**, только для частной сети и локальной подсети. Порт PostgreSQL для телефона не нужен.
4. В debug-приложении введите **тот же адрес без /health** в поле **Адрес сервера**: `http://<LAN-IP>:8000`. Нажмите **Проверить и подключиться**. На Android 17 и новее разрешите доступ к локальной сети. Если доступ отклонён, откройте разрешения приложения в системных настройках. После успешной проверки откроется вход. Сервер можно сменить через меню или ссылку на экране входа.
5. Зарегистрируйте тестового пользователя или войдите. Выберите дату, нажмите **+**, сохраните событие, проверьте его в режиме **День**. Перезапустите приложение. Адрес, сессия и сохранённое на сервере событие должны быть доступны.

Нативный HTTP-клиент обращается напрямую к API. CORS контролирует запросы из браузера, для Android-приложения запись в CORS_ORIGINS не требуется. Используйте тестовую учётную запись при проверке по HTTP. Debug допускает HTTP только для введённых частных IPv4 из диапазонов 10/8, 172.16/12 и 192.168/16, включая адрес хоста стандартного эмулятора `10.0.2.2`. Release требует HTTPS. Автоматические HTTP-перенаправления отключены. Смена адреса очищает сессию, JWT хранятся зашифрованными ключом Android Keystore.

## Доступные сценарии

Календарь сохраняет выбранную дату между режимами **Месяц / Неделя / День**. Даты с записями подсвечены. События поддерживают тип, описание, ссылку и интервал времени. Заметку можно привязать к дню или оставить без даты. Удаление требует подтверждения. На экране аналитики показаны суммы и распределения за текущую неделю или месяц. Общий счётчик отдельных заметок охватывает все даты, как в веб-клиенте. Кнопка ИИ запускает анализ на сервере через Ollama. В меню доступны напоминания по дате устройства и отметка о прочтении. Сервер предоставляет внутриприкладной список, отдельного API доставки push нет.

Визуальная основа — мобильный вариант Emerald и карточка входа из [Figma](https://www.figma.com/design/ErMqIpkZ9s7TJ3yMhttLDj). Для выбора даты и времени используются системные Android-диалоги. При чтении кадра формы Figma вернула ограничение запросов, поэтому набор полей сверен с веб-формой и контрактом API.

## Проверка

- Из папки Android Studio: `.\gradlew.bat testDebugUnitTest assembleDebug`. Устанавливаемый APK — `app\build\outputs\apk\debug\app-debug.apk`.
- APK успешно запущен через штатную MainActivity на эмуляторе. Экраны входа и календаря сверены со снимками Figma. Release тоже собран (`assembleRelease`); артефакт `app-release-unsigned.apk` предназначен для последующей подписи.
- На Android 15 (API 35) в эмуляторе выполнены 4 инструментальных теста, включая реальный FastAPI с временной SQLite. Проверены регистрация, вход, восстановление сессии, повтор запроса после 401, выбор режима, создание, изменение и удаление записей, статистика, чтение уведомления и выход. Прошли также 4 JVM-теста, включая правила HTTP, календарные границы и валидацию интервалов.
- Для повторения полного набора на стандартном эмуляторе запустите **отдельный тестовый API с одноразовой БД** на компьютере и выполните `.\gradlew.bat connectedDebugAndroidTest "-Pandroid.testInstrumentationRunnerArguments.calendarTestUrl=http://10.0.2.2:<порт>"`. Интеграционные тесты создают пользователей. Без параметра тесты, которым нужен сервер, пропускаются.
- Проверены итоговый release-манифест и ресурсы вариантов. Политика release задаёт `cleartextTrafficPermitted="false"`; debug использует отдельный ресурс и проверку адреса в клиенте. Основание: [Android Network Security Configuration](https://developer.android.com/privacy-and-security/security-config), [разрешение локальной сети в Android 17](https://developer.android.com/privacy-and-security/local-network-permission).
- Физический телефон по Wi-Fi, системный запрос разрешения на Android 17 и успешная генерация текста локальной моделью Ollama остаются для проверки на целевом окружении.
