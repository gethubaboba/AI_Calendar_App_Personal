## Результаты и ограничения

- В чистой копии прошли `npm ci`, `npm run build` и запуск production-сборки. Первичная сборка в рабочей папке получила Windows EPERM в существующем каталоге `.next`; разрешения этого каталога остаются особенностью локального окружения.
- В контейнере прошли обе проверки `python -m unittest -v test_calendar test_ai`. Для повторения интеграционной проверки нужна тестовая БД PostgreSQL с применёнными миграциями. Сценарии браузера выполнялись на временной установке. Нативный запуск API на Windows отдельно не проверялся.
- Согласованная авторизация MVP — email и пароль с JWT. Уведомления работают внутри приложения. Google/Microsoft OAuth, email/push, интерфейс шаблонов, контроллеры и сборщики метрик отложены. Существующий API шаблонов сохранён.
- При обновлении старой БД, созданной через `create_all`, требуется одноразовая сверка схемы перед `alembic stamp 0001`. [Инструкция по переходу](../README.md#переход-с-бд-созданной-через-create_all)
- При установке npm сообщил об уязвимости закреплённой версии Next.js 14.2.3. Обновление фреймворка остаётся отдельной задачей. Сборка также предупредила об устаревшем формате viewport и базе Browserslist.

## Проверка MCP-ассистента, 12 ноября 2026

- Проверены миграции до 0003 на отдельной PostgreSQL. Alembic не обнаружил расхождений с моделями. Прошли 13 тестов календаря, MCP, AI и существующих метрик, включая изоляцию владельцев, устаревший предпросмотр и повторное подтверждение.
- В изолированном Compose-проекте проверены запуск PowerShell, доступ к модели из контейнера API и оба режима остановки. Официальный JavaScript MCP SDK обнаружил три инструмента, создал предпросмотр заметки и прочёл её после подтверждения. Повторное подтверждение вернуло 404.
- Локальная модель Qwen через llama.cpp build 12179 прочла тестовую заметку для совета и подготовила новую заметку в режиме изменения. Это два проверенных сценария; качество ответов на другие формулировки не оценивалось.
- TypeScript и производственная сборка Next.js прошли. В Edge при эмуляции касания и ширине 375 px проверены загрузка XLSX, отмена, подтверждение и сообщение о дубликате. Физический телефон в этой проверке не использовался.
- При сборке npm сообщил о семи уязвимостях дерева зависимостей (две средней, четыре высокой и одна критической степени). Обновление и повторная проверка зависимостей остаются отдельной задачей. OAuth и внешняя доставка уведомлений по-прежнему отложены. [Запуск и интерфейс MCP](calendar_agent.md)
